# Sistema de Controle de Consultas - Exercício de Desenvolvimento de Software

Este repositório contém um **exercício prático** desenvolvido como parte do estudo de **desenvolvimento de software básico em linguagem C**.

## 📋 Objetivo

Criar um pequeno sistema de controle de consultas hospitalares, com funcionalidades simples de cadastro e agendamento, utilizando manipulação de arquivos `.txt` como base de dados.

## ⚙️ Funcionalidades

- Cadastro de **pacientes**
- Cadastro de **médicos**
- Agendamento de **consultas**
- Relatórios listando:
  - Consultas agendadas
  - Pacientes cadastrados
  - Médicos cadastrados

## 💾 Armazenamento

Todas as informações são armazenadas em arquivos `.txt`:
- `pacientes.txt`
- `medicos.txt`
- `consultas.txt`
- `totais.txt` (armazena os contadores de registros)

## 📌 Tecnologias

- Linguagem C
- Bibliotecas utilizadas: `stdio.h`, `string.h`, `windows.h`, `conio.h`

## 📚 Observações

Este projeto tem fins educacionais, sendo parte de uma atividade prática com o intuito de exercitar lógica de programação, estruturas de dados básicas e manipulação de arquivos.
